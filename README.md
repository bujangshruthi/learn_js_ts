# Learn JavaScript and TypeScript

A small, growing set of examples for learning JavaScript and TypeScript. The current lessons cover JavaScript basics, hot code, checking the Node.js environment, and identifier rules and naming conventions.

## Lessons

| File | Topic |
| --- | --- |
| [`chapter_1/01_basics.js`](chapter_1/01_basics.js) | Logging a message and using a variable |
| [`chapter_1/02_hotcode.js`](chapter_1/02_hotcode.js) | Hot code in a loop and calling a function |
| [`chapter_1/03_setupverficication.js`](chapter_1/03_setupverficication.js) | Checking the Node.js platform and architecture |
| [`chapter_03_Identifiers/06_identifiers.js`](chapter_03_Identifiers/06_identifiers.js) | Identifier rules with valid and invalid examples |
| [`chapter_03_Identifiers/07_namingconvention.js`](chapter_03_Identifiers/07_namingconvention.js) | JavaScript naming conventions and when to use them |

## Run an example

Install [Node.js](https://nodejs.org/) if it is not already available, then run a lesson from the project directory:

```sh
node chapter_1/01_basics.js
```

Replace the filename with another lesson to run a different example. These files are standalone scripts and do not require additional packages.
